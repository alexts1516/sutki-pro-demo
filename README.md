# Сутки·Pro — демо-прототип

Кликабельный прототип системы для владельца посуточной аренды в Астане (20–40 квартир): сайт для гостей «Astana Stay» (главная страница), панель владельца/администратора и мобильное приложение «Сутки·Pro Клининг». Чистый HTML/CSS/JS, без сборки и без внешних зависимостей.

**Все данные вымышленные (демо).** Изменения (заявки, трансферы, отчёты, сотрудники) хранятся только в localStorage вашего браузера; сбросить — кнопкой «Сбросить демо» на странице «Вход для команды».

## Что внутри

- **Сайт для гостей** — каталог 24 квартир, фильтры (даты, гости, район, цена, комнаты, «Можно с животными»), условная карта Астаны по районам.
  - **Большой календарь**: два месяца рядом на компьютере и прокручиваемый список месяцев на телефоне; недели начинаются с понедельника, прошедшие дни недоступны. Внутри квартиры занятые дни зачёркнуты, а период нельзя растянуть через занятые даты. Ночи и сумма считаются сразу.
  - **Компактный поиск**: когда большой блок поиска уходит за верх экрана, в шапке появляется строка «даты · гости · фильтры»; по нажатию раскрывается полный поиск.
  - **Животные**: 8 из 24 квартир принимают питомцев, у некоторых есть доплата 5 000 ₸ за проживание и ограничение «до 10 кг». На карточках есть значок, в квартире — правила, в форме — «Еду с животным» (отмечается только там, где можно).
  - **Трансфер**: отдельный раздел с таблицей цен. Направления «Из аэропорта», «В аэропорт» и «Туда и обратно» (со скидкой); аэропорт NQZ или вокзал «Нурлы Жол»; дата и время, номер рейса или поезда, пассажиры, багаж, детские кресла, класс «Стандарт» или «Минивэн». Если люди или багаж не помещаются в седан, класс переключается автоматически. Цена считается сразу. Трансфер можно заказать прямо в форме брони или отдельно, если жильё уже забронировано у нас, на Airbnb или Booking.
  - **Оплата**: 4 способа — картой онлайн (демо-форма), наличными, через Telegram или WhatsApp (показывается предпросмотр сообщения, ссылки не открываются).
- **Панель владельца**:
  - Календарь-шахматка, заявки со всех каналов (включая заказы трансфера и отметку «С животным»), уборки с фотоотчётами, ремонты (в т.ч. проблемы от клининга), финансы.
  - Трансферы: поездки с сайта со всеми деталями — табличка, класс машины, багаж, кресла. Можно назначить водителя, отметить выполнение или отменить поездку.
  - «Сотрудники»: роли, статус, последний вход, задачи, рейтинг, журнал действий, добавление сотрудника и отключение доступа.
- **Сутки·Pro Клининг** — задачи на сегодня и завтра, адрес и код двери, срочность заезда. Статусы: «Назначена → В пути → Убираю → Готово». Есть чек-лист, фото с камеры телефона (или демо-фото), «Сообщить о проблеме» и «Отправить отчёт». Цен, финансов и контактов гостей специалист по клинингу не видит, панель владельца для него закрыта.

## Файлы

- `index.html` + `assets/guest.js`, `assets/guest.css` — сайт для гостей.
- `team.html` — вход для команды.
- `login.html` — вход.
- `app.html` — панель владельца.
- `cleaning.html` + `assets/cleaning.js` — приложение для клининга.
- `guest.html`, `cleaner.html` — переадресация со старых адресов.
- `assets/data.js` — генерация демо-данных, одинаковых на всех страницах (включая правила для животных).
- `assets/store.js` — общее состояние, демо-вход, тарифы трансфера.
- `screenshots/` — скриншоты страниц.

Это прототип для презентации: настоящей авторизации, сервера и оплаты нет.
