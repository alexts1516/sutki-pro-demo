# Сутки·Pro — демо-прототип

Кликабельный прототип системы для владельца посуточной аренды в Астане (20–40 квартир): сайт для гостей, панель владельца/администратора и мобильное приложение уборщика. Чистый HTML/CSS/JS, без сборки и без внешних зависимостей.

**Все данные вымышленные (демо).** Изменения (заявки, отчёты, сотрудники) хранятся только в localStorage вашего браузера; сбросить — кнопкой «Сбросить демо» на главной.

## Что внутри

- **Сайт для гостей** — каталог 24 квартир, фильтры (даты, гости, район, цена, комнаты), условная карта Астаны по районам, карточка квартиры с календарём занятости, форма брони с трансфером и 4 способами оплаты: картой онлайн (демо-форма), наличными, Telegram, WhatsApp (предпросмотр сообщения, ссылки не открываются). Заявка сразу появляется у владельца в «Заявках» с источником «Сайт».
- **Панель владельца** — календарь-шахматка, заявки со всех каналов, уборки с фотоотчётами, ремонты (в т.ч. проблемы от уборщиков), финансы, трансферы и «Сотрудники»: роли, статус, последний вход, задачи, рейтинг, журнал действий, добавление сотрудника и отключение доступа.
- **Приложение уборщика** — задачи на сегодня/завтра, адрес и код двери, срочность заезда, статусы «Назначена → В пути → Убираю → Готово», чек-лист, фото с камеры телефона (или демо-фото), «Сообщить о проблеме», «Отправить отчёт». Цен, финансов и контактов гостей уборщик не видит; панель владельца для него закрыта.

## Файлы

`index.html` — главная, `guest.html` — сайт гостей, `login.html` — вход, `app.html` — панель, `cleaner.html` — уборщик.
`assets/data.js` — генерация демо-данных (одинаковых на всех страницах), `assets/store.js` — общее состояние и демо-вход.
`screenshots/` — скриншоты страниц.

Это прототип для презентации: настоящей авторизации, сервера и оплаты нет.
