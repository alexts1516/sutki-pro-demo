# Сутки·Pro — демо-прототип

Кликабельный прототип системы для владельца посуточной аренды в Астане (20–40 квартир). В нём:
- сайт для гостей «Astana Stay» (главная страница, RU/EN, 4 валюты);
- панель владельца/администратора;
- мобильное приложение для команды «Сутки·Pro Команда» (клининг и мастера), которое можно установить на телефон как PWA;
- одноразовые ссылки на задачу для внешних исполнителей.

Чистый HTML/CSS/JS, без сборки и без внешних зависимостей.

**Все данные вымышленные (демо).** Изменения (заявки, трансферы, отчёты, сотрудники, курсы валют) хранятся только в localStorage вашего браузера. Сбросить их можно кнопкой «Сбросить демо» на странице «Вход для команды».

## Что внутри

- **Сайт для гостей** — каталог 24 квартир, фильтры (даты, гости, район, цена, комнаты, «Можно с животными»), условная карта Астаны по районам.
  - **Центр, рядом с посольством США**: 16 из 24 квартир — в ЖК Хайвил (пр. Кабанбай батыра) в центре Астаны. Это видно в первом экране, в преимуществах, на карточках («рядом с посольством США»), в описании квартиры и на карте (метки «ЖК Хайвил» и «Посольство США»).
  - **Английская версия**: переключатель RU/EN в шапке. Выбор запоминается; при первом визите язык берётся из браузера (ru/kk → RU, иначе EN). Переведены весь интерфейс, описания и правила квартир, питомцы, трансфер, календарь (месяцы и дни недели), бронирование, оплата, подтверждения и подвал. Панели команды и владельца — на русском.
  - **Валюта**: переключатель ₸ KZT / ₽ RUB / $ USD / € EUR. Базовая валюта — тенге; цены пересчитываются по курсам владельца. Если владелец задал для квартиры ручную цену в валюте, показывается она. Выбор валюты запоминается (для EN по умолчанию — USD). Курсы в демо **условные, не реальные**.
  - **Большой календарь**: два месяца рядом на компьютере и прокручиваемый список месяцев на телефоне; недели начинаются с понедельника, прошедшие дни недоступны. Внутри квартиры занятые дни зачёркнуты, а период нельзя растянуть через занятые даты. Ночи и сумма считаются сразу.
  - **Компактный поиск**: когда большой блок поиска уходит за верх экрана, в шапке появляется строка «даты · гости · фильтры»; по нажатию раскрывается полный поиск.
  - **Животные**: 8 из 24 квартир принимают питомцев, у некоторых есть доплата 5 000 ₸ за проживание и ограничение «до 10 кг».
  - **Трансфер**: аэропорт NQZ или вокзал «Нурлы Жол», туда / обратно / туда и обратно со скидкой, багаж, кресла, класс машины, цена сразу. Можно заказать в форме брони или отдельно (если жильё забронировано у нас, на Airbnb или Booking).
  - **Оплата**: картой онлайн (демо-форма), наличными, через Telegram или WhatsApp (показывается предпросмотр сообщения, ссылки не открываются).
- **Панель владельца**:
  - Календарь-шахматка, заявки со всех каналов, уборки с фотоотчётами, ремонты, финансы, трансферы.
  - В «Заявках» с сайта видно, в какой валюте гость видел цену и на каком языке был сайт: «Гость видел: $217 · ≈ 110 000 ₸».
  - **Ремонты и задачи**: исполнителя выбирает владелец, автоматического назначения нет. Форма «Добавить задачу» (и «Изменить»):
    - описание текстом или голосом (демо-распознавание);
    - поиск квартиры («Хайвил 12», «Нурсая», номер);
    - тип работ: Сантехника / Электрика / Бытовая техника / Мебель / Другое — определяется по описанию, можно поменять;
    - срочность, фото, желаемая дата и время;
    - исполнитель: подходящие по типу работ мастера сверху (специализация, телефон, рейтинг, текущая загрузка). Можно выбрать «+ Новый исполнитель» (имя, телефон, специализация, галочка «Добавить в постоянные» или разовый) или «Не назначено». Переназначить можно в любой момент;
    - доступ в квартиру: «Код замка» (код сейфа виден исполнителю только пока задача активна), «Ключи у администратора» или «Нужно личное присутствие» (кто будет на месте и во сколько; задача помечается «сложная»).
    
    После сохранения сразу предлагается «Отправить ссылку исполнителю». Мастер с аккаунтом видит задачу в своём приложении и получает уведомление.
  - **Смета и оплата**: исполнитель присылает смету (работа + запчасти) из приложения или по ссылке. У владельца задача получает статус «Ожидает согласования» с кнопками «Согласовать» и «Отклонить» (с причиной). Итог по факту приходит с отчётом, дальше — «Отметить оплату». Согласованные сметы и итоговые суммы попадают в «Финансы» → «Ремонт и закупки» за нужный месяц и по квартире.
  - Ссылка на задачу: одноразовая ссылка для внешнего исполнителя, предпросмотр сообщения в Telegram/WhatsApp. Реально сообщение не отправляется — ссылку можно скопировать.
  - «Сотрудники»: роли (включая «Мастер»), статус, последний вход, задачи, рейтинг, журнал действий. Раздел **«Мастера и подрядчики»**: мастера с аккаунтом, постоянные и разовые подрядчики, загрузка, выполненные работы, расходы и история работ по каждому.
  - **«Настройки → Валюты и цены»** (только владелец):
    - курс каждой валюты («1 USD = 510 ₸»);
    - какие валюты показывать на сайте;
    - правило и шаг округления;
    - ручные цены за ночь по квартирам в конкретной валюте.
    
    Сохранение сразу отражается на открытом сайте для гостей. Кнопка «Вернуть демо-курсы» возвращает значения по умолчанию.
- **Сутки·Pro Команда** (`cleaning.html`) — одно приложение для клининга и мастеров.
  - Клининг: задачи на сегодня и завтра, код двери, чек-лист, фото, «Сообщить о проблеме», отчёт.
  - Мастер: свои ремонты, этапы «Назначена → В пути → В работе → Готово», доступ в квартиру (код / ключи у администратора / кто встретит), смета на согласование, фото до/после, итоговая стоимость, отчёт.
  - Установка на телефон (PWA): баннер «Установить на телефон». На Android открывается системный диалог, на iPhone показываются шаги: «Поделиться» → «На экран Домой».
  - Уведомления о новых задачах (кнопка «Симулировать новую заявку»). Уведомления работают, пока приложение открыто. Настоящий Web Push при закрытом приложении требует сервера — в демо его нет.
- **Задача по ссылке** (`task.html?t=…`) — страница для внешнего исполнителя без входа: описание, доступ в квартиру, смета на согласование, фото, итоговая стоимость, комментарий, «Отправить отчёт». Отчёт виден владельцу, только если открыт в том же браузере — в демо нет сервера.

## Бренд сайта для гостей — где менять

Название, логотип, цвета и контакты сайта для гостей собраны в **`assets/brand.js`**:
- `name`, `short`, `tagline`;
- `logoSVG` (сейчас временная заглушка-домик) или `logoImg: 'assets/logo.svg'` — путь к файлу логотипа;
- `colors` — задают CSS-переменные `--brand`, `--brand2`, `--accent`, `--accent2`;
- `contacts`.

Файл применяется ко всей странице: шапка, подвал, заголовок вкладки, значок вкладки, чат-предпросмотр, заказ трансфера.

Название продукта для команды «Сутки·Pro» — в `team.html`, `login.html`, `app.html`, `cleaning.html`, `task.html`, `manifest.webmanifest`. Иконки приложения — в `icons/`.

## Файлы

- `index.html` + `assets/guest.js`, `assets/guest.css` — сайт для гостей.
- `assets/brand.js` — бренд сайта для гостей.
- `assets/i18n.js` + `assets/i18n-en.js` — переключение языка и EN-словарь (ключ — точный русский текст).
- `team.html` — вход для команды; `login.html` — вход.
- `app.html` — панель владельца (включая «Настройки → Валюты и цены»).
- `cleaning.html` + `assets/cleaning.js`, `assets/master.js` — приложение команды (клининг и мастера).
- `assets/pwa.js`, `sw.js`, `manifest.webmanifest`, `icons/` — установка на телефон и уведомления.
- `task.html` — задача по одноразовой ссылке.
- `guest.html`, `cleaner.html` — переадресация со старых адресов.
- `assets/data.js` — генерация демо-данных, одинаковых на всех страницах.
- `assets/store.js` — общее состояние, демо-вход, тарифы трансфера, курсы валют.
- `screenshots/` — скриншоты страниц.

Это прототип для презентации: настоящей авторизации, сервера, push-уведомлений и оплаты нет.
