Сутки·Pro — демо серверной версии

как будет работать настоящий сервер: админка, приложение команды, ссылки

👋 Это демо. Данные хранятся только в вашем браузере — их видите только вы.

Нет настоящих оплат, Telegram-бота и сервера: всё, что бот отправил бы людям, видно по кнопке «💬 Telegram» внизу экрана.

Готовим демо-данные…

1. Войдите за любого — одним касанием

Сменить роль можно в любой момент — кнопка «👥 Сменить роль» внизу справа.

2. Попробуйте сценарий

🚗 Бронь с трансфером → водитель

  1. Владелец → «Брони и заявки» → заявка с трансфером → «Подтвердить».
  2. Заказ ушёл водителям: откройте «💬 Telegram» — у водителей сообщение с кнопкой «✋ Беру».
  3. Нажмите «Беру» за Руслана (в Telegram-демо) или войдите водителем Руслан и нажмите «Беру» в приложении — первый получает заказ, номер квартиры и телефон гостя открываются только ему.
  4. Шаги: «Выехал» → «На месте» → «Гость в машине» → «Завершить».
  5. Владелец → «Трансферы» → карточка: «Оплата гостя → бизнес» и «Выплата водителю».

🔧 Заявка мастеру → смета по фото → доп. расход

  1. Владелец → «Заявки мастерам» → «Новая заявка»: исполнитель Master Electric, смета по фото, можно приложить фото.
  2. Войдите мастером Master Electric → заявка → «Смета» → отправить.
  3. Владелец → заявка → «Одобрить» смету.
  4. Мастер → «Начать работу» → «Доп. расход»; владелец его одобряет.
  5. Мастер → «Выполнено» с отчётом — сумма попадает в «Финансы».

💰 Комиссия с трансферов → финансы

  1. Владелец → «Настройки» → «Бизнес оставляет процент», например 20% → «Сохранить».
  2. Там же — «Везёт сам владелец — вся сумма бизнесу».
  3. «Финансы» → выручка от гостей, выплаты водителям (должны / выплачено), что осталось бизнесу.

3. Гость: новая заявка с трансфером

Как с сайта гостей. После отправки войдите владельцем и подтвердите заявку — заказ уйдёт водителям.

Что здесь не настоящее

  • Telegram-бот — сообщения показываются во вкладке «💬 Telegram (демо)», никуда не уходят.
  • Онлайн-оплата (CloudPayments / PayLink) выключена — оплату гостя отмечают вручную: наличные / карта / онлайн.
  • Слежение за рейсами и облачное хранилище фото выключены; фото сохраняются в браузере (уменьшенными).
  • Сервера и хостинга нет: тот же код сервера работает прямо в странице, «база» — в браузере.
